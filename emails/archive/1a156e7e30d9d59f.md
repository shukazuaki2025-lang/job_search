■ 面试准备（结合你的课程和项目）
1. 公司一句话：做 X86/ARM 嵌入式主板和整机 ODM 的公司，教育白板 OPS 电脑是强项，也做工控机、网安设备、AI 服务器；苏州是研发中心
2. 操作系统基础（大概率问）：BIOS 和 UEFI 区别；系统启动流程（上电 → BIOS/UEFI → 引导程序 → 内核 → 用户空间）；Windows 驱动在哪看（设备管理器）、怎么装；Linux 怎么看硬件（lspci、lsusb、dmesg）；分区 MBR/GPT
3. Linux 实操：常用命令（ls、cd、grep、chmod、apt、systemctl、ssh）；怎么写一个 Bash 小脚本；你在 ROS 里配环境踩过的坑，讲一个具体例子
4. 兼容性测试思路：一块新主板装上系统后外设不识别，你怎么查——先看设备管理器/dmesg 有没有识别 → 驱动版本 → BIOS 设置 → 换系统版本复现 → 记录并反馈。这是「问题排查」题，用你单片机调试的经历类比
5. 英语：可能让你读一段英文规格书或驱动说明，四级水平读懂关键词即可
6. 为什么自动化专业来投系统岗：自动化学了计算机控制、微机原理、嵌入式，对「控制器底层的计算机系统」感兴趣；ROS 让你熟悉 Linux
7. 反问：带教是谁；实习生的工作是测试为主还是镜像/驱动为主；出差频率；实习转正流程
