## 推荐顺序

1. **蔚空微纳、铭想芯创：先核地址与资格。** 前者有硬件测试列表线索，后者有本科嵌入式列表线索；两者均未确认10公里道路路线及2028届接收条件。
2. **把“寒假开始＋春季继续”作为主要沟通方案。** 连续3–6个月的岗位往往无法只做一个寒假；周3天和周5天必须按你真正能保证的完整工作日分别谈。
3. **丁丁停车先看截止，晶捷先看时长。** 丁丁停车3天/周、3个月，研发成分较少；晶捷5天/周、6个月，只有能长期稳定到岗才值得继续。南京城铁虽明确列2028届，但在雨花台，留作跨区备选。

以上是行动建议，不代表已经联系、投递或获得录用。具体证据和招聘状态见完整档案。
