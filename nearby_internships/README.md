1. **铭想芯创**：先在BOSS确认2028届本科、准确办公门牌、每周出勤/实习月份，以及是否真正做MCU/驱动调试。地点未确认前不按“近校已核实”安排。

3. **圭步微电子（扩展区）**：官方明确有实习，先问本科能投的芯片测试、FPGA、雷达应用岗位；嵌入式岗位招聘列表显示硕士，不默认本科可投。
